# PFA 2026

Projet de fin d'année (PFA) 2026, application développée avec Flutter dans le cadre de ma formation d'ingénieure en Génie Logiciel et Ingénierie des Données à l'IIT Sfax.

## Technologies
- Flutter / Dart

## Lancer le projet
1. Installer Flutter
2. Cloner le dépôt : `git clone https://github.com/meriembenrbeh/pfa-2026.git`
3. Entrer dans le dossier : `cd pfa-2026`
4. Installer les dépendances : `flutter pub get`
5. Lancer l'application : `flutter run`
